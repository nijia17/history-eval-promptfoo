# 历史人物内容生成 · AI 输出自动化评测

> 用自动化评测的方式，量化「知识库约束」能不能降低大模型生成历史内容时的事实性幻觉。

本项目的评测框架基于开源工具 [promptfoo](https://promptfoo.dev)（LLM 评测工具包）搭建，
测试用例、评测维度、对照设计与结论分析为本人设计。

---

## 一、项目背景

在搭建历史人物科普内容生成流程时，发现大模型存在**事实性幻觉**问题——
生成的内容看似通顺，但会出现时间线错位、人物事迹张冠李戴、数字前后矛盾等错误。

初步排查后定位出三层成因：

| 层级 | 问题 |
| --- | --- |
| 检索层 | 知识库采用精确字段匹配，用户输入稍有偏差即召回为空 |
| 流程层 | 召回为空时流程缺少兜底分支，模型失去事实依据 |
| 数据层 | 知识库资料颗粒度不足，模型被迫扩写，扩写部分无事实约束 |

针对「数据层」成因，本项目的验证目标是：

> **如果把真实资料作为上下文注入生成环节，模型的事实准确性会不会显著提升？**

## 二、评测设计

### 2.1 A/B 对照

| 分组 | 提示词 | 说明 |
| --- | --- | --- |
| **对照组** | `prompts/baseline.txt` | 直接提问，不提供任何资料 |
| **实验组** | `prompts/kb_grounded.txt` | 注入该人物的知识库资料后再生成 |

两组使用**同一个模型、同一批测试用例**，唯一变量是「是否注入知识库资料」。

### 2.2 测试用例

测试用例由自建的 108 条历史人物知识库自动生成，共 **20 条**，刻意覆盖不同难度：

- **10 条冷门人物**：模型参数化知识相对薄弱的对象
  （郦道元、顾恺之、徐光启、宋应星、郭守敬、赵孟頫、吴道子、李煜、张仪、谢安）
- **8 条知名人物**：模型本身已熟知的对象
  （孔子、李白、诸葛亮、武则天、苏轼、岳飞、王阳明、康熙）
- **2 条库外人物**：知识库中不存在（林黛玉、哈利波特），用于验证「无依据拒答」是否生效

每条用例的变量：

```yaml
vars:
  person: 人物姓名
  facts:  该人物在知识库中的完整资料（出生时间 / 主要经历 / 历史贡献 / 历史评价）
```

### 2.3 评测维度

| 维度 | 实现方式 | 说明 |
| --- | --- | --- |
| **事实准确性** | `llm-rubric` 断言 | 由模型充当评委，判断回答是否准确、是否编造资料外的事实（阈值 0.7） |
| **无依据拒答** | `llm-rubric` 断言 | 对库外人物，判断模型是否明确表示资料不足、而非凭空编造 |
| **响应性能** | `latency` 断言 | 单次生成耗时是否超过 30 秒 |

## 四、快速开始

### 第 1 步：获取 API Key

前往 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 注册并创建一个 API Key
（本项目单次评测总成本约 0.1 元）。

### 第 2 步：配置密钥

把 `.env.example` 复制一份并重命名为 `.env`，填入你的 Key：

```
DEEPSEEK_API_KEY=sk-你的密钥
```

### 第 3 步：运行评测

双击 `run.bat`，或在命令行执行：

```bash
promptfoo eval     # 执行评测
promptfoo view     # 在浏览器中查看结果
```

## 五、评测结果

| 分组 | 事实准确性通过率 |
| --- | --- |
| 对照组（无知识库约束） | **13 / 20 = 65%** |
| 实验组（注入知识库资料） | **20 / 20 = 100%** |

**注入知识库资料后，事实准确性提升 35 个百分点。** 7 条差异用例全部为「对照组失败、实验组通过」：

| 测试用例 | 对照组出现的错误 |
| --- | --- |
| 郦道元 | 出生时间记为约 470 年（资料为约 466 年） |
| 顾恺之 | 出生年记为 344、去世年记为 405（资料为 348 / 409） |
| 徐光启 | 官职记为文渊阁大学士（资料为东阁大学士） |
| 吴道子 | 出生年记为 680（资料为 685），并编造「向张旭学习草书」 |
| 赵孟頫 | 外放时间与职官任命同资料存在出入 |
| 张仪 | 编造「楚国令尹门下做门客被鞭打」等资料中不存在的事迹 |
| 哈利波特 | 未拒答，直接编造虚构人物的完整生平 |

### 一个值得注意的发现

**8 位知名人物（孔子、李白、诸葛亮、武则天、苏轼、岳飞、王阳明、康熙）在两组中全部通过。**

这说明模型对大众熟知人物的参数化知识已经足够可靠，**知识库约束的价值主要体现在冷门人物的事实校准上**。

这个结论对实际工作有直接指导意义：知识库的补充优先级，应当放在模型的「知识盲区」而非「已知领域」——把资源投入冷门人物，边际收益最高。

## 六、可以怎么用

- **内容质量验收**：把评测集接入内容生产流程，每次调整提示词或知识库后回归跑一遍，防止质量退化；
- **提示词迭代**：用同一套测试集对比不同提示词版本的通过率，让优化有据可依；
- **知识库补全**：统计哪些人物的失败率最高，反向定位知识库资料薄弱的条目。
